# Data Cleaning & Preparation

A hands-on module focused on turning raw tabular data into a cleaner, analysis-ready dataset.

## Purpose

This repository is part of a structured data-science learning series. Its goal is to document practical skills clearly and keep the corresponding notebook easy to review.

## Topics Covered

- Dataset inspection
- Missing-value handling
- Duplicate and inconsistent-data checks
- Data-type correction
- Preparing cleaned features for analysis or modeling

## Main Notebook

`notebooks/Data_Cleaning_Preparation.ipynb`

## Skills Demonstrated

- Data cleaning
- Preprocessing
- Data-quality checks
- Python
- Pandas

## Repository Focus

This repository is intentionally kept as a focused learning module rather than presented as a full production or research project. It supports the broader portfolio by documenting foundational data-science workflow skills.

## Tech Stack
